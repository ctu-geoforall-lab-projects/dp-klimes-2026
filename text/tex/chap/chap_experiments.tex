\chapter{Experiments and Results} 
\label{chap:experiments}

This chapter presents the experimental design and results of the study. The experimental design defines all transfer learning and baseline experiments investigated, along with the normalization strategies applied to each. For each experiment, summary metrics for all normalization strategies are reported in the main text, while figures including confusion matrices and visual examples of predicted cloud masks are shown for the best performing normalization strategy only. Full detailed metrics for all normalization variants are provided in Appendix~\ref{chap:appendix}.

\section{Experimental Design}
\label{sec:experimental_design}

The experiments in this study are organized into two 
groups: baseline experiments and transfer learning 
experiments. The baseline experiments provide reference 
points against which transfer learning performance is 
assessed. The transfer learning experiments investigate 
two settings — transductive and inductive — as defined 
in Section~\ref{sec:transfer}. All transfer learning 
experiments use a U-Net model pretrained on Sentinel-2 
data, which is described in Section~\ref{sec:s2_training}.

\subsection{Baseline Experiments}

Two baseline experiments are included. MAJA \cite{hagolle2010} serves as a classical reference, evaluated directly on the VEN$\mu$S test 
set without any training or normalization, as 
described in Section~\ref{sec:evaluation}.

\subsection{Transfer Learning Experiments}

Transfer learning experiments are based on a Sentinel-2 pretrained model. Prior to any transfer learning, a U-Net model is trained on the Sentinel-2 dataset for each normalization strategy, producing three pretrained models, that serve as starting points for the transfer learning experiments. The S2 training results are reported in Section~\ref{sec:s2_training}.

In the transductive setting, the pretrained model is applied directly to VEN$\mu$S data without any modification to model weights. The model produces 3-class predictions including cloud shadow, but quantitative metrics are computed on two classes (cloud and clear) only, with shadow predictions collapsed into the clear class. Shadow detection quality is assessed through visual inspection. Three normalization strategies are evaluated in the transductive setting: raw, fixed Z-score with Sentinel-2 statistics, and dynamic Z-score.

In the inductive setting, three fine-tuning strategies 
are investigated, differing in the degree of network 
adaptation. All inductive experiments produce 2-class 
outputs and are evaluated on cloud and clear classes. 
Early stopping with a patience of 100 epochs is used 
for all fine-tuning experiments. Four normalization 
strategies are evaluated for each fine-tuning variant: 
raw, fixed Z-score with Sentinel-2 statistics, fixed 
Z-score with VEN$\mu$S statistics, and dynamic 
Z-score.

\section{Sentinel-2 Model Training}
\label{sec:s2_training}

Before transfer learning experiments can be conducted, a U-Net model is trained on the Sentinel-2 dataset for each normalization strategy. The resulting models serve as starting points for all subsequent transfer learning experiments. The S2 test set metrics are reported here as a reference for source domain performance.

The per-class and overall metrics for all three Sentinel-2 models on the S2 test set are summarized in Tables~\ref{tab:s2_perclass} and \ref{tab:s2_overall}.

The dynamic Z-score normalization produced substantially better results than both raw and fixed Z-score strategies across all metrics and all classes. The dynamic model achieved an mF1 of 0.865 and mIoU of 0.766, compared to 0.766 and 0.623 for fixed Z-score and 0.690 and 0.537 for raw data. This improvement can likely be explained by the per-tile normalization, which reduces radiometric differences between patches captured under varying atmospheric conditions and at different geographic locations, making the problem more consistent across the whole dataset.

Shadow detection shows the largest performance gap between normalization strategies. Dynamic Z-score achieves an F1 of 0.791 for shadow, compared to 0.706 for fixed Z-score and 0.534 for raw data. Shadow is consistently the hardest class across all normalizations, which is expected given its spectral similarity to other dark surfaces and the fact that the quality of shadow class annotations was the poorest of all classes, as discussed further in Chapter~\ref{chap:discussion}.

The fixed Z-score model required significantly more epochs to converge (798) compared to raw (294) and dynamic (521), suggesting that global statistics introduce more radiometric variation across patches than per-tile normalization. Training and validation 
loss curves for all three models are provided in 
Appendix~\ref{app:loss_curves}.

The three trained models serve as starting points for the transfer learning experiments described in the following sections. Whether the performance advantage of dynamic Z-score on the S2 test set carries over to VEN$\mu$S transfer is one of the questions investigated in this study.

The confusion matrix for the dynamic Z-score model on the S2 test set is shown in Figure~\ref{fig:s2_confusion}. The confusion matrix reveals that the model performs well on the cloud and clear classes, with recall values of 0.85 and 0.94. Shadow shows the weakest performance, with a recall of 0.68, and is most frequently confused with the clear class 
(0.15) and the cloud class (0.17). The cloud class 
shows some confusion with the clear class (0.12), 
which is expected at cloud boundaries where the 
transition between classes is gradual.
